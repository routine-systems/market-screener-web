# Market screener web instructions

Before editing or publishing a dashboard template, API function, navigation
item, appearance visualization, tooltip, period mapping, linked filter, or
rotation control, read and follow
[`../chartink-dashboard/notes/dashboard_style_guide.md`](../chartink-dashboard/notes/dashboard_style_guide.md).

Use the guide's acceptance checklist after every material dashboard change.
Treat the guide as canonical unless the user explicitly changes a convention;
then update the guide in the same task.
